# Mouse Click Debouncer

A lightweight Windows utility that prevents accidental left-mouse double-clicks caused by worn or faulty mouse switches.

## Features

- Prevents accidental left-click double-clicks
- Adjustable debounce interval
- 50–500 ms options
- System tray support
- Minimal CPU usage
- Windows 10/11
- No background services
- Free and open source

## Recommended Setting

150 ms is a good starting point for most faulty mouse switches.

## How It Works

The application filters repeated left mouse button events that occur within the selected debounce interval.

For example:

Physical mouse:
Click → Click

Application:
Click → Blocked
